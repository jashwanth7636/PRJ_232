PROJECT INFORMATION

AI-Powered Maintenance
Chatbot for Electrical Substations

A machine-learning and AI-assisted system designed to support electrical substation fault classification and maintenance information retrieval.

PROJECT

PRJ_232

The project combines a trained electrical fault classification model with technical document retrieval and a conversational AI layer.

DOMAIN

Artificial Intelligence / Machine Learning

The system applies supervised machine learning to electrical measurements and combines the prediction component with technical maintenance information.

SDG

SYSTEM ARCHITECTURE

How PRJ_232 Works

01

Electrical Measurements

Three-phase voltage and current measurements are provided to the system.

→
02

Trained ML Model

A Random Forest classifier predicts one of the supported electrical fault classes.

→
03

Knowledge Retrieval

Relevant technical information is retrieved from the maintenance document collection.

→
04

AI Assistant

The retrieved engineering context is used to generate conversational maintenance assistance.

KEY COMPONENTS

System Components

Trained Fault Classifier Random Forest machine-learning model
Technical Document Retrieval TF-IDF based retrieval from maintenance manuals
Conversational AI Natural-language engineering assistance
Web Interface FastAPI backend with responsive web frontend
