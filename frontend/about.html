Supervised Machine Learning: Model Evaluation & Benchmarks
Empirical model selection based on stratified test split metrics
📊

Multiple supervised classification architectures were rigorously trained and evaluated against identical 3-phase electrical sensor telemetry datasets (Ia, Ib, Ic, Va, Vb, Vc). The empirical results demonstrate clear superiority of the Random Forest ensemble:

Model Algorithm Validation Acc Test Acc Precision Recall F1-Score Deployment Status
Random Forest Classifier (100 Trees) 86.94% 85.34% 85.37% 85.34% 85.34% ACTIVE PRODUCTION
XGBoost Classifier 83.10% 82.78% 82.80% 82.78% 82.75% Benchmark Baseline
Logistic Regression 36.12% 35.37% 32.40% 35.37% 31.25% Rejected (Linear Underfitting)
Scientific Rationale: The Random Forest ensemble was selected for production deployment (saved as best_fault_model.joblib) because it demonstrated the highest generalization accuracy (85.34% test accuracy) while exhibiting robust resistance to noise and sensor non-linearities common in real-world current and potential transformers (CT/PT).
